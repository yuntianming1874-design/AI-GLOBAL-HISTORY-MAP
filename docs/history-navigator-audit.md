## 三、DEEPEN 审计结论

- **参与者 deepen（事件 → 人物）**：全部合理 ✅（参与者即事件真实人物，如
  玄武门→李世民、希吉拉→穆罕默德+阿布·伯克尔）。
- **年份 deepen（年份 → 事件）**：新增"排除当前事件自身"——Talas 上下文不再
  推荐"怛罗斯之战（751 年）"作为深化（自指冗余）。✅

## 四、COMPARE 审计结论

全部 40 条按规则（±10 年 + significance ≥ 3 + 不同文明）生成，抽查代表性条目：

| 当前 | compare | 判定 |
|---|---|---|
| 唐朝建立 (618) | 希吉拉 (622) | ✅ 时代可比 |
| 怛罗斯之战 (751) | 阿拔斯革命 (750) | ✅ 同期世界 |
| 安史之乱 (755) | 阿拔斯革命 (750) | ✅ 同期 |
| 巴格达建城 (762) | 安史之乱 (755) | ✅ |
