# V0.3 Phase 2 — Historical Learning Experience (Narrative / World / Lifespan)

> 基线：v0.3-phase2（39d7f32）· 本阶段在**不破坏 Phase 1 已验收行为**的前提下，
> 将 Journey 从"可交互时间线"升级为"具有因果解释能力的历史学习体验"。

## A. Narrative Story Engine

**数据模型扩展**（`src/lib/learning/journeyTypes.ts`，JourneyStep）：

```ts
question / questionEn            // 核心历史问题（Story Panel 开头）
whyImportant / whyImportantEn    // 为什么重要（数据驱动，替代 narrator 模板）
nextStepReason / nextStepReasonEn // 为什么接下来会发生什么（因果衔接）
keyFactEntityIds?: string[]      // 关键事实实体（必须存在于 seed）
people?: string[]                // 相关人物分组（缺省回退 surroundingEntities）
locations?: string[]             // 相关地点分组
civilizations?: string[]         // 相关文明分组
```

- **分组字段是可选覆盖**：缺省时由 `surroundingEntities` 按 type 派生——
  不建立第二套实体数据源。
- `journeyRepository` 校验升级：`keyFactEntityIds` 任意已知类型；
  `people/locations/civilizations` 必须类型匹配；任何未知 id fail-fast。
- `narrator` 升级：关键事实按 `keyFactEntityIds` 顺序解析（事件/人物/文明/地点
  全类型支持），缺省回退"主事件 + 周边事件 + 主人物"；provenance
  disputed/unknown 仍进入 `uncertaintyNotes`。

**StoryPanel UI**（连续叙事，非碎片卡片）：

```
[Step 标题] [Step 序号] [时间]
[核心历史问题]  ← question（金色左边框引用块）
[历史叙述]     ← narrative（连续散文）
[为什么重要]   ← whyImportant（数据驱动）
[关键事实]     ← narrator keyFacts（repository-backed）
[为什么接下来会发生什么] ← nextStepReason
[相关人物 / 文明 / 地点 / 事件] ← 分组 chips
[← Previous | Continue →]
```

## B. World Context Enhancement

- 新纯逻辑 `src/lib/learning/worldContext.ts`（可测试）：
  - `WORLD_REGIONS`：East Asia / Central Asia / Middle East / Europe / Japan /
    Southeast Asia / Americas
  - `CIV_TO_REGION`：12 个文明 → 显示区域的**固定 UI 分组映射**（非历史主张）
  - `groupCivilizationsByRegion` / `selectEventsForYear`（点事件 ±5 年 /
    区间事件覆盖该年）/ `worldRegionLabel`（双语）
- `ContemporaryWorldPanel` 重构：每区域显示 文明（名称+色+年代）、关键事件
  （provenance formatter 日期 + 标题 + 简介首句 + confidence 徽标：
  disputed→"存在争议"、unverified/low→"未经核实"）；无数据 → "暂无足够可靠
  的结构化资料"。**禁止 AI 编造**——事件只来自 /api/events。

## C. Person Lifespan Timeline

- 新纯逻辑 `src/lib/learning/lifespan.ts`：
  - `buildPersonLifespanModel`（生卒 + PersonRole[] 区间 + 参与事件 +
    activeAtYear），日期全部经 `formatHistoricalDate/formatLifespan/formatYearSpan`
  - `selectPeopleAliveAtYear`（该年活跃人物，importance 排序）
  - `yearToPosition` / `lifespanRange`（500–1000 钳制）
- 新组件 `PersonLifespanTimeline.tsx`：每人物一行（姓名 → 点击 OPEN_PERSON
  打开现有 PersonDrawer；生卒区间条；角色区间条；关键事件点；
  Journey 当前年竖线联动）。**不建立第二套人物数据源**。
- `JourneyExplorer` 集成：`step.year` 驱动（`step.personId` 存在时优先显示该人）。
